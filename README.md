# VNStockLab

VNStockLab is a web-based technical analysis and decision-support platform for the Vietnamese stock market.

The project is under active development. Its goal is to provide transparent, reproducible tools that help investors explore market conditions, evaluate technical signals, test strategies, and manage portfolio risk.

> **Disclaimer:** VNStockLab is a decision-support tool and does not provide guaranteed investment advice. Users remain responsible for their own investment decisions.
